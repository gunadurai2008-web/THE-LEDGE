# THE LEDGE

THE LEDGE is a shared AI development workspace for projects, agent activity, code changes, and project knowledge.

## MVP stack

- Frontend: React + Vite
- Backend: Python + FastAPI
- Database: PostgreSQL (to be added in a later step)
- Agent execution and live activity: added in later MVP steps

## Repository layout

- `frontend/` — web application
- `backend/` — API and agent services
- `docs/` — product scope and project documentation
